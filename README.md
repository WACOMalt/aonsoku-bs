  <h3>Aonsoku-BS</h3>
  <p>
    A personal fork of Aonsoku, the modern desktop client for Navidrome/Subsonic servers built with React and Electron. This fork adds...</p>
    
* Reworked UI for Mobile support. Android via APK, PWA, or Web. iOS theoretically via Web (Native iOS not planned but if there's interest I'll see how feasible it is)
* Synced Jams with join by link or code. Optional guest control of queue.
* Session transfer. Pick up your phone and you can transfer your current session to it, and vice versa.
* Gapless playback on Desktop and Android
* Pageless scrolling on Artist lists and posters views  
* Tag editor for Navidrome admins: edit tags and covers, look up MusicBrainz, identify songs by sound. Needs a small Navidrome plugin: see [tagger-plugin/README.md](tagger-plugin/README.md).
    
LLMs are used in the creation of this fork and as such I cannot recommend anyone use it over the official project. While I do my best to maintain quality, I'm one guy with an LLM coding agent, so temper your expectations. I do plan to continue keeping this fork up to date, as I use it myself. I hope you enjoy the additional functionality!
Feel free to report issues. I will attempt to address them.
